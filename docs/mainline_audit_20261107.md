## 规格结论

- PDF 第 3 页给出 2≤N1<N2≤4，四项共享 N1/N2。第 4 页任务二明确每样本 0..3 类、每测试项 1750 份、未知类别 N≤5。FAQ 的“两类”描述与正文更广范围不一致，按正文保留 0..3。
- 第 13–15 页规定 100 MSps、100 ms、交错 int16 IQ，单文件 40,000,000 字节；已知编码 0..19，未知从 20 开始。
- 第 15 页规定相对频率 ±50 MHz，必须逐一列出同频多段突发。时域定位保留在推理事件归档中，最低提交三列没有强制时间列。
- 官方任务一示例的 Sheet1 表头、文件 ID 文本和数字类别与导出器一致。已知映射全部 20 项匹配；不能把模型原生类别 ID 直接当官方 ID，特别是 FIMI 两类顺序不同。
- 官方任务二示例第 14 行明确以 [-1,0,0] 表示仅干扰场景。示例还有注释行、可选参数列及超出正文频带的演示值；使用其格式/空场景约定，但频率范围按正文。
- 任务二两个场景共用字母 N，但没有明确给出跨批次未知编号身份对应关系；保持各测试项匿名编号，不根据文件名强行对齐型号身份。
