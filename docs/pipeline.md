# 系统链路与实现边界

## 数据与时频表示

原始DAT按交错int16 I/Q读取，默认小端、100 MSps；真实长度按完整I/Q对计算。前端将固定50ms观察窗转换为原生512×750频谱。采集率100MHz与122.88MHz的统一输出坐标网格是两种参数，不能混用；频率轴采用FFT方向，最终相对频偏按Hz导出。

训练随机取窗，验证使用固定窗并允许缓存频谱；随机训练窗不复用文件级检测框。部署以50ms步长覆盖完整记录，`cover`为尾段补窗，后续按物理时间合并重复观测。输入MAT需要明确幅值/图像域，PNG必须满足约定的原生频谱尺寸，避免对数变换或resize做两遍。

`util/spectrogram_frontend.py`定义前端契约；`data/iq_dat_loader.py`负责DAT训练加载；`util/eval_common.py`负责部署输入发现、窗口计划、投票及配置解析。

## 检测、分组与突发

YOLO在前端渲染的灰度频谱上检测候选框；物理事件策略使用实际检测置信度、有效采集频带、对比度和时间结构筛选候选。分组由`util/preprocess.py`负责，`util/event_detection.py`负责物理事件规范化。

普通频率分组与跳频关联处理不同结构。当前配置使用hopping/shape关联：允许框宽高存在差异，周期证据作为辅助，仍检查时间重叠、冲突比例、脉冲数和覆盖，避免把同时存在的不同信号强行并组。没有因本次代码整理改变关联阈值或评分公式。

分类使用分组框构建二值mask，ResNet18提取表示并由分类头输出类别。主线训练取主分组做CE；mask_amplitude、全分组训练和SupCon保留为明确的开发实验。检测组、分类输入、跨窗轨迹和最终物理突发是不同层次：同一频率上不相连的多个突发必须保留独立时间段；类别相同不能作为把它们合并成一个大框的理由。

`util/group_predictor.py`共用逐组分类，`util/single_signal_eval.py`与`util/multi_signal_eval.py`只组织单/多信号输出；全部预测通过`scripts/evaluate_single_signal.py`。训练器只负责训练与验证，不再包含另一套GT实例匹配推理引擎。

## 已知拒识

分类器倒数层特征先L2归一化，再按有效观察聚合为轨迹表示。参考集来自训练划分，校准集独立。一个原始记录的多个轨迹不能当作多个独立记录反复增加统计权重。

对参考特征z和类别均值μ，计算记录平衡的共享类内协方差Σ，向各向同性矩阵收缩：

```text
μ_c = Σ(i属于c) w_i z_i / Σ(i属于c) w_i
Σ = Σ_i w_i (z_i - μ_yi)(z_i - μ_yi)^T
Σ_λ = (1-λ)Σ + λ·max(tr(Σ)/d, 1e-12)·I
s(z) = min_c (z - μ_c)^T Σ_λ^(-1) (z - μ_c)
```

主线λ=0.1。权重由原始记录身份分配并全局规范化。类别标签仍来自分类头投票，最近均值仅参与拒识评分；不能把二者混成同一个分类规则。阈值按独立已知校准记录的主轨迹分数和目标误拒率0.01确定，未知测试标签不参与均值、协方差或阈值拟合。

Maha实现见`util/mahalanobis.py`，记录权重与校准聚合见`util/recording_features.py`。profile绑定分类器、检测器、前端/分组源码、切片配置和相关依赖版本；不匹配时重新训练/校准，不修改已存签名。

## 未知发现与公开数量范围

被拒识的有效轨迹进入未知池；`no_signal`、运行错误及没有特征的未决行不应伪装成真实新类特征。任务一每个原始单信号记录选主轨迹参与拟合，附属轨迹沿用对应记录的发现标签，避免重复加权；任务二保留不同组件可能属于不同来源的结构。

主线使用原始L2特征、10邻居谱聚类；根据公开数量范围比较候选K、支持记录数及无标签内部诊断，再对任务一联合选择满足N1<N2的数量组合。很小或缺乏支持的簇不能凭“看起来太少”就断言误分类；未满足约束会记录失败而不会编造匿名ID。

谱聚类由`util/spectral_discovery.py`实现，统一发现接口在`util/unknown_discovery.py`；`recluster_competition_batch.py`负责任务一联合选择。密度与其他后端保留用于开发矩阵比较，不改变冻结的已知拒识结果。

## 结果和计量单位

`predictions.csv`是规范预测表，`unknown_features.npz`保存冻结未知候选，运行JSON记录配置、错误和计数。任务一按文件/原始记录评价；任务二按物理突发及频率区间导出。开集检测F1、已知准确率、未知ARI/NMI必须注明各自覆盖率和评价单位。二维PCA/t-SNE仅用于展示，不能代替原始特征中的聚类评价。
